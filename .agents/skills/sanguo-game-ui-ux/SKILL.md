# 三国塔防 UI/UX 商业化规范

## 1. 严禁研发文案与英文枚举外泄
- 所有界面文本必须通过中文映射字典转换后展示，**禁止直接拼接以下内部标识**：
  - 属性键：`atk_pct` → `攻击力`，`hp_pct` → `城防生命`，`crit_rate` → `暴击率`，`crit_dmg` → `暴击伤害`，`elem_pct` → `元素伤害`
  - 维度键：`melee` → `近战`，`ranged` → `远程`，`magic` → `法术`
  - 元素键：`physical` → `物理`，`fire` → `火攻`，`lightning` → `雷策`，`ice` → `寒冰`，`poison` → `剧毒`
- 禁止在界面出现 `(预留)`、`(二期开放)`、`(三期)`、`企业主体 AppID` 等研发阶段占位词；暂未开放的功能统一使用商业化文案（如 `敬请期待`、`暂未开启` 或直接提供单机模拟体验）。
- 百分比、数量、单位禁止跨行折断（如 `+40%`、`Lv.1` 不可拆成两行），数值变化必须带全单位（如 `+0% → +6%`）。

## 2. 防溢出、安全区与对比度底线
- **设计分辨率与黑边**：`750×1334` 下采用 `ResolutionPolicy.FIXED_WIDTH`（长屏自动延伸背景底图至 `1680` 高避免上下黑边，核心交互保持在 `y ∈ [-610, 590]`）。
- **微信右上角胶囊安全区**：顶部栏与HUD必须避开右上角胶囊区域（`y > 590` 仅放背景装饰）。
- **弹出框防溢出**：列表项超过 4 项的弹窗（如神兵库、武将词条、宝石背包）必须采用 `ScrollView` 或紧凑栅格计算边界，确保最后一项底边与底部 `关闭` 按钮之间留有 `>= 16px` 间距。
- **动态元素防越界**：城防/战场 `Graphics` 循环绘制元素必须做边界裁剪（如城垛 `x + w <= 310`）。
- **文字对比度**：叠在亮色场景图（桃花/日照/草地）上的计时器、倒计时、提示条必须加深色半透明圆角底衬（`alpha >= 200`）或文字描边（`LabelOutline`）。

## 3. 层级栈与交互状态机
- **弹窗遮罩层级**：所有全屏弹窗必须挂载在独立 `modalLayer` 上（位于普通 `hud` 之上），严禁让 HUD 按钮（如 `查看战况`）穿透遮罩亮在半透明黑幕上方。
- **按钮可用态分离**：点数不足、材料不足、已满级、今日上限用完时，按钮必须切换为置灰禁用皮肤（`#546E7A` / 灰按钮图），禁止亮绿误导可点击；并在强化/洗炼按钮旁明示消耗材料与拥有量（如 `铜钱 160 / 锻造石 2`）。
- **状态提示一致**：连续多次触发三选一弹窗时，标题必须区分「开局点将」与「第 N 次点将 / 主公升级」。
- **视觉统一**：优先使用 `UIFactory` 提供的九宫格古风皮肤（按钮/卡片/底框/进度条）与小图标，逐步淘汰纯色直角/圆角色块。
