# 三国塔防｜逐界面动效清单

适用：Cocos Creator 3.8.7，微信小游戏。组件名对应 `sanguo_fx` 组件库，位于 `assets/scripts/fx/`。

优先级：**P0** 不用新美术、半天内可做完；**P1** 需要少量素材（高光条、粒子图）；**P2** 需要美术或 Spine 资源。

## 组件总览

| 组件 | 说明 | 主要 API |
| --- | --- | --- |
| ButtonFX | 按压缩放回弹 | 挂节点即生效；`pressScale` / `downTime` / `upTime` |
| IdleBreath | 待机循环（呼吸/浮动/摆动） | `mode`(Scale/Float/Swing)；`amp`/`period`/`interval`/`horizontal` |
| ShineSweep | 高光扫光条 | `loop=true` 自动循环；`playOnce()` 事件触发 |
| PanelPopup | 弹窗弹出/收起 | `open(cb)` / `close(cb)`；`mask` 背景遮罩 |
| NumberRoll | 数字滚动+弹跳 | `rollTo(n)` / `setNow(n)`；`tintOnIncrease` |
| FloatText | 飘字（静态，对象池） | `FloatText.show(layer, pos, text, style)`；`warmup(16)` |
| ScreenShake | 屏幕震动 | `ScreenShake.play(amp, dur)`（空安全静态） |
| HitFlash | 受击白闪+挤压 | `play()` / `holdFlash()`；需 hit-flash.mtl |
| HitStop | 顿帧卡肉（静态） | `HitStop.trigger(sec, skels)`；`HitStop.reset()` |
| SpineActor | Spine 武将/敌人封装 | `idle/attack/skill/hurt/die/win/play`；`face(right)` |
| GlowPulse | 光晕脉冲（透明度+缩放） | `minOpacity`/`maxOpacity`/`scaleAmp`/`period` |
| SpinLoop | 匀速旋转（射线/光圈） | `speed`（度/秒，负=顺时针）；`randomStart` |
| FxPool | 飞行图标/粒子对象池（静态） | `acquire(parent, opts)` / `release(node)` / `warmup(20)` |

## 八、建议施工顺序

1. **第 1 天（P0 全部）**：ButtonFX 批量挂载、红点摆动（IdleBreath Swing + interval=3）、Tab 切换 tween、资源数字滚动（NumberRoll）、开始战斗按钮呼吸、武将卡入场波浪延迟
2. **第 2~3 天（战斗手感）**：FloatText.warmup、HitFlash、ScreenShake、HitStop 接入战斗逻辑；`dt *= HitStop.scale` 加到战斗 update
3. **第 4~5 天（P1）**：制作 shine_bar / glow_circle / rays_star 三张图 → ShineSweep 扫光、GlowPulse 光晕、宝箱开启动画、FxPool 飞行图标（道具飞资源条）、升级反馈（FloatStyle.levelUp）
4. **之后（P2）**：SpineActor 接入主力武将、技能粒子、背景粒子、全屏转场

## 九、性能红线（微信真机）

- 同屏粒子总数建议 ≤ 150，低端机减半
- 常驻循环 tween 数量控制在 30 个以内；列表中屏幕外节点 `active = false` 即可，IdleBreath / GlowPulse 会自动停止
- 扫光、光晕用同一张图集（shine_bar + glow_circle + rays_star 三张合一），避免打断合批
- 所有飘字、特效节点走 `FxPool` / `FloatText` 对象池，战斗中禁止 `new Node`；切场景调 `FloatText.clear()` 和 `FxPool.clear()`
- `HitStop.reset()` 在战斗结束/场景卸载时调用，防止 Spine timeScale 残留
- 所有组件用 `Tween.stopAllByTag`（按 tag 精确停止），不用 `stopAllByTarget`，同节点可安全并行挂多个组件
