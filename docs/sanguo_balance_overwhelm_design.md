# 三国塔防 · 威胁与战力平衡设计(吸血鬼式碾压爽感)v1

> 问题:20 波中敌人数量虽增加,但英雄变多、技能变强后,敌人普遍存活不到 5 秒、走不出多远;前期顶住则全局碾压,前期顶不住则升级过慢、基本过不去。
> 目标:**"被压 → 成型 → 释放"的碾压爽感**,而不是"一路无聊的碾压",同时堵住前期崩盘。
> 前置:20 波 / 270 秒的时间线、16 次升级的曲线、`PathTrack` 弧长移动、坑位类型、军令/无双(第二阶段 2A)。
> **重要说明**:文中的"战力曲线 P(t)"是我按截图里的成长速度(Lv9 时约 7 名武将等)做的**估算**,所有数值都是起点,必须用 §10 的方法用实测数据校准。

---

## 1. 问题诊断(量化)

### 1.1 战力与威胁的增长倍率严重失衡

| | 开局 | 约 W10(110s) | 约 W19(215s) |
|---|---|---|---|
| 敌方血量池(旧配置:数量 × `1+0.06×(w-1)`) | 1× | 约 3~4× | 约 8~9× |
| 玩家战力(武将数 × 技能等级 × 军策 × 坑位/羁绊) | 1× | **约 25~30×** | **约 70×** |

旧配置里敌人血量只线性增长 6%/波,W20 仅为 W1 的 2.1 倍,而玩家战力是乘法叠加的,**曲线越拉越开**。

### 1.2 数量是 AOE 游戏里最弱的威胁

你的武将多为范围/穿透类,敌人越密反而打得越爽。所以"波数多、每波数量多"不构成威胁,只是经验燃料。

### 1.3 成长与击杀速度绑死,形成纯正反馈

```
击杀快 → 经验多 → 升级快 → 更强 → 击杀更快   (滚雪球)
击杀慢 → 经验少 → 升级慢 → 更弱 → 漏更多   (死亡螺旋)
```

两个结局都来自这一个环,而且分水岭落在前 30~60 秒,受首发武将和选项运气影响最大。

### 1.4 火力网覆盖整条路径,后段设计被浪费

敌人死得太早,夹缝位、门前位、第二第三条横路几乎用不上,第二阶段的坑位类型也就没有意义。

## 2. 设计原则

1. **碾压必须"挣来的"**:先压,再成型,再释放。没有"被压"就没有"碾压"的快感。
2. **威胁与时间绑定,不与玩家战力绑定**:波次按时间推进,拖延只会更难(参考 Risk of Rain 2)。
3. **用血量成长对抗战力成长**:敌人单体血量按**指数**增长,数量只负责"密度"和"视觉"。
4. **释放窗口要主动设计**:割草波 + 宝箱强化 + 多级连升 + 无双,而不是靠数值自然碾压。
5. **前期只做保底,不做加成**:追赶经验和下行辅助只在"落后"时生效,领先的玩家不被惩罚(保持吸血鬼式的滚雪球爽感)。
6. **终局有压轴**:Boss 战是最后的紧张感来源(类似吸血鬼的死神),不能被前面的碾压直接秒掉。

## 3. 核心模型

### 3.1 战力比 R

```
R = (当波时长内玩家的总输出量) ÷ (当波敌人总血量池)
  = (DPS × 波时长) ÷ T
```

| R 值 | 含义 |
|---|---|
| < 0.8 | 严重吃紧,会明显漏怪、积压到下一波 |
| 0.8~1.0 | 压力波:刚好能顶住,会积压一部分 |
| 1.0~1.5 | 平稳,清完后有少量空档 |
| > 1.8 | 碾压:敌人大片倒下,连斩飙升 |

> DPS 取"单体等效"。AOE 会让群体敌人死得比 R 估算更快——这正好强化了割草波的碾压感,也让带护甲/精英的压力波更难清。

### 3.2 三种波型

| 波型 | R 目标 | 敌人构成 | 玩家感受 |
|---|---|---|---|
| **压力波** | 0.78~1.0 | 精英 / 盾兵 / 骑兵 / 军医为主,小兵少 | 紧张、要集火、要放军令 |
| **成型波** | 1.1~1.5 | 普通小兵,数量中等 | 稳定,刚获得强化后的验证 |
| **释放波(割草波)** | 1.7~2.6 | **大量低血量杂兵**,高出怪密度 | 满屏数字、连斩飙升、连升多级 |

### 3.3 目标曲线(R 随时间)

```
R
2.6 |                                          ·            ·W19
2.0 |                  ·W10 ·W11
1.7 |                                    ·W15
1.4 |           ·W8·W9    ·W13
1.2 | ·W1~W6                  
1.0 |                           ·W14
0.9 |             ·W7     ·W12      ·W16 W17 W18  ·W20(Boss)
0.8 |
    +---------------------------------------------------------→ 时间
     缓启动    压力峰1   释放1    压力峰2  释放2  压力峰3(最高) 终极释放  Boss
```

节奏:**缓启动 → 压力峰1(W7)→ 释放1(W10~11)→ 压力峰2(W12/14)→ 释放2(W15)→ 压力峰3(W16~18,最紧)→ 终极释放(W19)→ Boss(W20)。**

### 3.4 战力曲线 P(t) 假设(待校准)

| 时间(s) | 0 | 10 | 20 | 30 | 45 | 60 | 75 | 90 | 105 | 120 | 140 | 160 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| P(开局=1) | 1 | 2.2 | 3.6 | 5 | 7.5 | 11 | 15 | 20 | 25 | 31 | 38 | 46 |

| 时间(s) | 180 | 200 | 220 | 240 | 270 |
|---|---|---|---|---|---|
| P | 55 | 64 | 74 | 85 | 95 |

对应的假设:前 30 秒武将数 1→4;W9(约 90s)约 7 名武将;之后靠技能升级、羁绊、进化与军策持续增长。

### 3.5 预算公式

```
DPS(t)   = d0 × P(t)                         // d0:单位战力的 DPS,按 W1 定标
T(w)     = d0 × P(w) × 波时长 ÷ R目标(w)       // 该波目标血量池
HP倍率 h(w) = 1.15^(w-1)                      // 敌人单体血量倍率(指数,时间绑定)
等效小兵数 B(w) = T(w) ÷ h(w)                  // 该波要凑出的"小兵当量"
B = N × f + Σ(特殊敌人倍数 × 数量)               // N:小兵数;f:杂兵系数(普通=1,割草波<1)
```

W1 定标:6 只小兵、`h=1`、R=1.25,得 **d0 ≈ 0.47 HP0/s**(HP0 = W1 小兵血量)。

> 这套公式的用途是:**当 P(t) 实测值变了,重新代入就能算出一套自洽的出怪表**,不再靠感觉调数字。

## 5. 释放窗口设计(让碾压是"挣来的")

### 5.1 割草波(释放波)的包装

| 手段 | 说明 |
|---|---|
| **正面横幅** | "乌合之众来袭",用金/绿色,让玩家一看就知道"这是送经验的" |
| **高密度出怪** | 4~4.7 只/秒,同屏敌人上限 60,到上限时暂停补怪,避免掉帧 |
| **杂兵低血量 + 高速度** | 死得快、冲得快,AOE 一扫一片 |
| **连斩与怒气飙升** | 释放波里连斩应能轻松触发 25/50 里程碑,怒气快速充能 |
| **经验球洪流** | 大量经验球吸附,配合经验条快速滚动 |
| **连升多级** | 释放波内预期连续升 **2 级**,选项弹窗不堵塞战斗(见下) |

**连升处理**:同时满足多次升级时,弹窗依次出现,每次选择后立刻继续,**不要等到所有升级完成才恢复战斗**;第二次弹窗之前给 0.5 秒战斗画面,让玩家看到刚选的强化立刻生效。

### 5.2 精英宝箱 = 压力峰之后的"强化跳变"

压力波的奖励就是通往释放的钥匙:

| 精英来源 | 宝箱内容 | 强化跳变(战力) |
|---|---|---|
| W7 精英 | 1 次高品质三选一(必含羁绊推进或新武将) | 约 +15% |
| W12 双精英 | 2 次选择(其中 1 次保底羁绊升档 / 进化卡) | 约 +20% |
| W16~W18 精英 | 每个 1 次稀有选择 + 怒气 +15 | 约 +15%/个 |

**这是 P(t) 中"阶梯上升"的主要来源**。压力波 R<1 时,击杀精英 → 宝箱 → 战力跳变 → 下一波 R 回升,这个循环就是"被压 → 成型 → 释放"的节奏骨架。

### 5.3 无双充能与释放窗口对齐

- 压力波里的精英击杀、漏怪都会给怒气,**压力峰结束时通常能攒满无双**,释放波开头直接打出无双,爽感叠加。
- 压力峰1(W7 前后)预计攒满第 1 次无双(约 75~90 秒),压力峰3(W16~18)预计攒满第 3~4 次。

## 6. 压力峰设计(质量威胁,保持紧张)

吸血鬼式碾压不等于全程无压力。压力波的"压"来自**血量集中**和**机制**,而不是数量。

### 6.1 压力波的构成

| 波 | 压力来源 | 玩家要做的事 |
|---|---|---|
| W7 | 首个精英将领,血量 15× | 集火、放军令、调整坑位 |
| W9 | 盾兵:受伤 -40%,AOE/穿透 -20% | 换成单体/高伤武将 |
| W12 | 双精英同时到来 | 号令三军 / 万箭齐发 |
| W14 | 骑兵冲刺:速度 ×1.8 | 擂鼓减速,门前位守线 |
| W16~18 | 精英连续 + 军医回血 | 优先点杀军医,保存无双 |
| W20 | Boss | 见 §8 |

### 6.2 入口冲锋护体(让敌人走得更远)

针对"敌人死在入口"的问题,给**普通小兵、精英、盾兵、骑兵、军医**(不含杂兵)加一个短暂护体:

```
受到的伤害 × (0.7 + 0.3 × min(s / (0.25 × 路径总长), 1))
// s=0 时 -30% 伤害,走到路径 25% 处恢复为 0%
```

- 作用:**把杀伤区间往路径中段推**,让夹缝位和第二条横路有用武之地。
- 对 R 的影响:相当于前 25% 路径上敌人有效血量上升,整体约 +7%,不会改变整体曲线。
- 视觉:敌人脚下有一圈浅色护盾,随前进逐渐变淡,让玩家看懂"这些在入口难打"。
- **杂兵无护体**,保持割草波的碾压感。

### 6.3 击杀深度目标(新增核心监控指标)

击杀深度 = 敌人被击杀时的 `s / 路径总长`(漏怪记为 100%)。

| 波型 | 平均击杀深度目标 |
|---|---|
| 开局波(W1~W4) | 30~50% |
| 铺垫/成型波 | 35~60% |
| **释放波(割草)** | **10~35%**(死得快才爽) |
| **压力波** | **60~95%**,允许少量漏怪 |
| Boss | ≥ 70%,最后阶段接近城门 |

**这张表替代了"敌人必须存活 X 秒"的做法**:释放波里敌人死得快是设计目标,但压力波里敌人必须能走很远。

## 7. 防崩盘:前期保底与成长兜底

### 7.1 追赶经验(只在落后时生效)

```ts
const expected = expectedLevel(t);          // 根据 levelTargets 查表
const delta = expected - player.level;      // 落后几级
const expMul = delta >= 3 ? 2.0 : delta >= 2 ? 1.5 : delta >= 1 ? 1.2 : 1.0;
```

- **只加不减**:玩家领先时不惩罚,保持滚雪球的快感。
- 不在 UI 上展示倍率,避免玩家感到被"照顾"。

### 7.2 让"没打死"也能成长

| 机制 | 数值 |
|---|---|
| 漏怪经验 | 敌人到达城门时给自身 **50%** 经验 |
| 波次结算经验 | 每波完成 +当前升级所需经验的 **12%** |
| 精英/Boss 宝箱 | 不受击杀速度影响(§5.2) |

三者合起来保证:**即使打得慢,升级也不会完全停滞。**

### 7.3 开局均衡:所有首发武将都得"能扛 W1~W3"

| 检查项 | 标准 |
|---|---|
| 首发三选一的构成 | **至少 2 个输出型**,不让三个全是辅助/控制 |
| 单人通过线 | 任何首发武将单独面对 W1~W3,R ≥ 1.0 |
| 偏弱的首发(如华佗) | 提高基础攻击,或开局送一个基础军令(万箭齐发 Lv1) |

测试方法:每个首发武将各跑 30 局"不做任何操作"的自动对局,统计 W4 前城墙血量和升级时间点。

### 7.4 缓启动

- W1~W3 敌人移速 **×0.85**,给玩家反应时间。
- 第 2 个武将在 **12 秒内**出现(保底规则,已在第1阶段 §2.3)。
- 前 40 秒的失败率目标:**普通玩家 < 3%**。

### 7.5 下行动态辅助(只帮落后者,有上限)

```
压力指数 PI = 该波结束时场上剩余敌人血量 ÷ 该波预算 T
触发:连续 2 个非压力、非 Boss 波的 PI > 0.5
效果:下一波小兵血量 -10%,出怪间隔 +10%;再触发 → -20% / +20%
限制:每局最多触发 3 次;Boss 波不生效;不在 UI 展示
```

- **没有上行调整**:领先的玩家不会被加难度,保持吸血鬼式的碾压体验。
- 这是兜底而非主要手段,先靠 §7.1~§7.4 解决大部分问题。

### 7.6 与"绝境三选一"联动

血量 <30% 的"绝境三选一"保留。如果玩家在 W12 之前就触发,**额外给一次追赶经验加成**(×1.5,持续 20 秒),帮助快速恢复战力。

## 8. Boss 决战(压轴的紧张感)

### 8.1 基础参数

| 项 | 值 |
|---|---|
| 登场 | 第 235 秒(W20 开始后 15 秒) |
| 血量 | **80 × h(20) ≈ 1138 HP0** |
| 速度 | 小兵的 0.7 倍,走完路径约 38 秒 |
| 预期击杀 | 平均构筑 + 1~2 次无双/军令 ≈ 22~29 秒 |
| 抵达城门时间 | 约第 273 秒(未被击杀的话) |

### 8.2 三阶段

| 阶段 | 触发 | 机制 | 目的 |
|---|---|---|---|
| 一阶段 | 登场 | 正常行进,周围有 2 只精英护卫 | 先清护卫,给输出窗口 |
| 二阶段 | 血量 70% | 获得 5% 最大血量的护盾 + 召唤小兵潮;期间对 AOE 免疫 0.5s | 逼玩家换目标 |
| 三阶段 | 血量 35% | **狂暴**:移速 +40%,攻击城墙更猛 | 制造"最后冲刺"的紧迫感 |

### 8.3 狂暴计时

270 秒(W20 结束)后 Boss 仍未被击杀:**每 10 秒全场敌人 +10% 移速和对城墙伤害**,直到 Boss 死亡。避免出现"一直拖时间磨死 Boss"的局面。

### 8.4 抵达城门后

Boss 到达城门后不再前进,持续攻击城墙(每秒 **3%** 城墙最大血量),此时玩家仍可输出。这个"倒计时"本身就是压轴的紧张感。

### 8.5 击杀演出

沿用第1阶段:慢动作 0.5 秒 + 镜头推近 + 大量掉落 + 结算滚动。

## 10. 校准方法

### 10.1 先测 P(t),再动数值

**不要直接改出怪表**,先测出你真实的战力曲线:

1. 做一个"靶场"调试模式:固定时间点(30/60/90/…/240s),生成一个 **血量极高、不会死亡的靶子**,持续 10 秒,记录全体武将总伤害,得到 `DPS(t)`。
2. 在 3 组不同构筑下各测一次,取**中位数**作为 `P(t)`,换算成 `P = DPS(t) ÷ d0`。
3. 把实测 P(t) 代入下面的预算函数,得到新的 `T(w)`、`B(w)`,再反推 N 和 h。

```ts
// tools/BudgetCalc.ts
export function budget(
  wave: { start: number; end: number; R: number; special: number /*Σ倍数×数量*/; f: number },
  P: (t: number) => number,
  d0: number,
  hMul: number,
) {
  const dur = wave.end - wave.start;
  const pAvg = avg(wave.start, wave.end, P);
  const T = d0 * pAvg * dur / wave.R;       // 目标血量池
  const B = T / hMul;                        // 小兵当量
  const N = Math.round((B - wave.special) / wave.f);
  return { T, B, N };
}
```

### 10.2 调参顺序(很重要)

| 步 | 调什么 | 原因 |
|---|---|---|
| 1 | **P(t) 实测** | 其他一切依赖它 |
| 2 | **h(w) 的底数**(1.15) | 控制整体强度斜率,最先对齐 |
| 3 | 压力波的 R 与特殊敌人数量 | 决定紧张感 |
| 4 | 释放波的 N 和 f | 决定割草密度 |
| 5 | 经验表、追赶参数 | 对齐升级时间 |
| 6 | 前 40 秒 | 保证起步稳 |
| 7 | Boss | 最后对齐终局 |

**一次只改一类**,每改完跑 §9.3 的批量对局看一张表,而不是凭手感。

### 10.3 埋点(沿用并扩展第1阶段 §8)

| 指标 | 用途 |
|---|---|
| 每波实测 R、PI | 对照 §3.3 目标曲线 |
| **击杀深度分布**(按波型) | 对照 §6.3 |
| 升级时间点 vs 目标 | 校准经验 |
| 城墙血量曲线(每 5 秒) | 看是否呈现"锯齿"(压力峰掉、释放波稳) |
| 追赶经验、下行辅助触发次数与时机 | 判断保底是否过强/过弱 |
| 各首发武将的通关率 | 找出"陷阱首发" |
| 各来源伤害占比 | 判断是武将、羁绊还是军令在撑场面 |

**城墙血量曲线应该是锯齿形**:压力峰掉血 → 释放波恢复(或至少稳定)。如果是一条平滑下降线,说明节奏没有做出来。
