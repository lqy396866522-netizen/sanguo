# 需求整理 01：军需商城页面美术与布局优化

## 1. 优化目标
针对当前「军需商店」偏暗色静态平铺卡片的现状，在不破坏现有每日限购、广告宝箱、购买扣费与动效逻辑的前提下，升级为具备三国商业化厚涂质感的「军需账房」视觉风格。

---

## 2. 页面结构与视觉规范

### 2.1 全屏背景与安全区
- 使用竖版古风暗红木纹商铺/军需账台背景（`bg_shop.jpg`，`540×960`，部署时按长屏规则延伸铺满 `750×1750` 消除上下黑边）。
- 所有可交互控件保持在 `y ∈ [-520, 580]` 微信安全区内。

### 2.2 顶部飞檐横幅与胶囊货币栏
- **飞檐标题栏**：无字古风木纹飞檐横幅底板（`ui_banner_eave.png`）居中叠加「军需商店 · 每日补给」金白高对比描边文字。
- **独立胶囊货币槽**：原纯文本行拆分为 **元宝 / 铜钱 / 粮草** 三枚圆角暗底金边胶囊框（使用 `ui_bar_bg` 或圆角胶囊底板），左侧放立体小图标，数字继续挂载 `NumberRoll` 滚动动效。

### 2.3 日常补给货架（6 行商品卡）
- **卡片容器**：替换冷紫框为暖棕木纹金边厚涂卡片（`ui_card_wood.png`，九宫格拉伸），可领/可买高亮、已售罄置灰。
- **立体厚涂道具图标**：
  - 每日军需宝箱：`icon_chest_gold`（金边厚涂宝箱）
  - 锻造石 ×10：`icon_forge_ore`（亮红锻造矿石）
  - 洗炼石 ×5：`icon_refine_crystal`（紫晶洗炼晶石）
  - 精良宝石袋：`icon_gem_pouch`（翡翠玉佩锦囊）
  - 名将将魂 ×10：`icon_hero_chest`（红金将魂箱）
  - 行军粮草 ×25：`icon_stamina_bag`（麦穗军粮布袋）
- **价签按钮交互升级**：右侧购买按钮改为软倒角卡通立体按钮，**按钮内部左侧嵌入对应货币图标**（如 `[铜钱] 400铜钱`、`[元宝] 40元宝`），已领取/已售罄切灰态按钮。

### 2.4 分割横条与尊享特权礼包（3 行暗红金边卡）
- **分割标题**：使用无字古风金纹横条（`ui_divider_bar.png`）叠「尊享特权与超值礼包」。
- **暗红特权卡（`ui_card_red_vip.png`）**：
  - 主公尊享月卡：金元宝堆红垫盘图标（`icon_ingot_tray`）+ 旋转光芒底衬；
  - 首充无双礼包：弩箭卷轴礼盒图标（`icon_crossbow_gift`）+ 右上角摇摆「超值」高光角标；
  - 6480 元宝军饷：大箱满溢金币宝箱（`icon_treasure_pile`）+ 环绕金币与光晕脉冲。

## 3. 出图与体积约束
- 新增资产统一放入 `assets/resources/art/` 并在 `ArtAssetManager.ts` 与 `docs/ART.md` 登记，严格控制新增总增量，确保全首包 `assets/resources/art/ <= 800 KB`。
- 若 AI 抠图后飞檐或特殊装饰边缘需精修，保留对应文件 Key 供后续直接同名替换。
