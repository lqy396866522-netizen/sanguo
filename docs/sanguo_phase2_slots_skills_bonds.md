### 2.2 统一属性修饰器 `StatBlock`（必须先于坑位/羁绊/军令落地）

所有属性来源（局外养成、坑位加成、辅助光环、羁绊、进化、军令 Buff、无双狂暴）均通过 `StatBlock` 计算，确保可按 `source` 整体增删、零残留、支持确定性回放。

#### 计算公式
```
最终值 = (基础值 + Σflat) × (1 + Σpct) × Π(1 + mul_i)
```
> **约束**：常规来源（局外、坑位、羁绊、词条）全部进 `pct`（同桶相加防指数失控）；仅限时爆发（如无双狂暴 `+30%` 伤害）允许进 `mul`。

#### 代码骨架（`assets/scripts/core/StatBlock.ts`）

```ts
export type Stat =
  | 'atk' | 'atkSpeed' | 'range' | 'crit' | 'critDmg'
  | 'dmgVsElite' | 'dmgVsBoss' | 'fireDmg' | 'poisonDmg'
  | 'meleeDmg' | 'rangedDmg' | 'cdReduce' | 'rageGain';

export interface Modifier {
  stat: Stat;
  kind: 'flat' | 'pct' | 'mul';
  value: number;
  source: string;     // 'meta:equip' | 'meta:gem' | 'meta:talent' | 'meta:weapon' | 'meta:talisman' | 'meta:hero_lv'
                      // 'slot:highland' | 'slot:aura' | 'bond:wuhu:3' | 'evo:H01' | 'skill:cmd_rally' | 'musou:fury'
  expireAt?: number;  // 限时 Buff 失效战斗时间（与 BattleWorld.elapsed 对齐，保证回放一致）
}

export class StatBlock {
  constructor(private base: Record<Stat, number>) {}
  private mods: Modifier[] = [];
  private dirty = true;
  private cache: Partial<Record<Stat, number>> = {};

  add(m: Modifier) { this.mods.push(m); this.dirty = true; }
  removeBySource(src: string) { this.mods = this.mods.filter((m) => m.source !== src); this.dirty = true; }
  removeBySourcePrefix(p: string) { this.mods = this.mods.filter((m) => !m.source.startsWith(p)); this.dirty = true; }

  get(stat: Stat, now: number): number {
    let flat = 0, pct = 0, mul = 1;
    for (const m of this.mods) {
      if (m.stat !== stat) continue;
      if (m.expireAt !== undefined && m.expireAt <= now) continue;
      if (m.kind === 'flat') flat += m.value;
      else if (m.kind === 'pct') pct += m.value;
      else mul *= (1 + m.value);
    }
    return (this.base[stat] + flat) * (1 + pct) * mul;
  }
}
```

#### 现有局外成长迁移约定（仅影响基础属性）
- 开局实例化武将时，将现有 `lordBonus` 中的装备 6 件套（`meta:equip`）、宝石词条（`meta:gem`）、主公天赋（`meta:talent`）、神兵（`meta:weapon`）、传奇兵符（`meta:talisman`）、武将局外等级（`meta:hero_lv`）全部转为 `Modifier` 注入 `StatBlock`。
- **边界**：第 2 阶段局外成长**不改变**坑位数、军令槽数和进化解锁，只在数据结构中预埋扩展口（见 §13）。

## 4. 主公军令（主动技能 × 5）

### 4.1 军令池与数值

以 **`ATK_ref`** = 当前全体已上阵武将 `StatBlock.get('atk', now)` 的均值作为统一缩放基准（无武将时取 `lordBonus.baseAtk`），确保军令从 W1 到 W20 始终有效。

| 军令 ID & 名称 | 操作方式 | 基础效果（Lv.1） | 冷却 | 适用场景 |
|---|---|---|---|---|
| `CMD_ARROW` **万箭齐发** | 拖拽到战场选点 | 半径 `140px`，持续 `2.5s`，每 `0.25s` 一跳，每跳 `0.5 × ATK_ref` 物理范围伤害 | 20s | 释放波/簇清场、弱首发兜底 |

| `CMD_DRUM` **擂鼓** | 点击即放 | 全场敌人移速 **-40%**，持续 `5s` | 28s | W14 骑兵冲锋、Boss 狂暴控速 |

| `CMD_LOG` **滚木礌石** | 拖拽到路径附近 | 从投影点 `s` 沿路径**逆行**滚动 `300px`，命中造成 `1.5 × ATK_ref` 伤害并击退 `80px`（`s -= 80`，Boss 减半） | 22s | 门前急救、打断推线 |

## 12. 已确认决策归档（v2）

以下 6 项核心决策已全部拍板并固化进本文档：

1. **坑位模型**：改为每关固定 **8~9 个带类型预设坑位 + 硬吸附**，维持 `maxHeroes = 8`，取消随机坑位与任意空地摆放。
2. **进化 / 无双 / 现有超武关系**：现有 12 名武将的 `H0X_SW`（原“无双·xxx”）**直接合并升级为进化形态**并改为绝学名；“军策”专指被动、“军令”专指主动、“无双”专指怒气大招，彻底消除重名。
3. **开局军令**：开局点将后接「军令 3 选 1」，且华佗/貂蝉首发保底含「万箭齐发」；双军令槽，Lv.6 保底第 2 槽。
4. **无双自动释放**：手动释放军令/无双享 **+20% 效果**；自动模式下军令自动放，无双在满足「场上敌人 ≥ 12 只 或 存在精英/Boss」时自动释放。
5. **武将与羁绊范围**：第 2 阶段不新增武将，基于现有 12 名武将落地 **7 组可用羁绊**（含 2 人档「魏武」），「江东」与「桃园结义」预留待后续新武将到位后启用；武将仍维持无血量。
6. **局外成长边界**：第 2 阶段局外成长仅通过 `meta:` 修饰器统一接入基础属性，不改变坑位数/军令槽/进化解锁，仅预埋接口字段。
