# 需求整理 02：主公装备页面 Q 版流云 UI 与全局底部导航优化

## 1. 优化目标
针对当前「主公装备」页面边框偏冷硬锐利、整体暗灰的观感，全面转向与屏幕中央 Q 版主公相契合的「暖木纹 + 流云金边 + 卡通厚涂高光立体按钮 + 饱满 Q 版底导」视觉体系。

---

## 2. 核心设计规范与保留约束

### 2.1 圆润饱满的轮廓与暖木纹装饰
- **暖木纹全屏底图（`bg_lord.jpg`）**：替换冷紫灰背景为温和三国暖木纹/营帐暗纹底图（`540×960` 铺满长屏）。
- **圆角木纹与流云金边底板（`ui_panel_cloud.png`）**：
  - 弱化原本硬直尖锐的金属边框；
  - 应用于 **顶部主公状态栏**（辅以顶部小金角装饰）、**中央主公展示台** 以及 **下方大型背包区底板**。

### 2.2 明快高光与卡通厚涂质感按钮
- 统一采用更清亮高光色泽与软倒角立体卡通按钮九宫格皮肤（`ui_btn_c_gold.png`、`ui_btn_c_brown.png`、`ui_btn_c_green.png`、`ui_btn_c_blue.png`、`ui_btn_c_red.png`）：
  - **「装备锻造」主按钮** & **「一键合成 (5合1)」按钮**：采用明亮暖金渐变高光软倒角按钮，保留扫光与红点呼吸；
  - **「方案 1~3」** & **「宝石 / 装备 / 强化工坊」**：选中态使用亮金立体凸起胶囊按钮，未选中态采用柔和暖棕灰按钮（去掉生硬纯矩形白黄线条下划线，改用立体按钮本身切换与轻弹反馈）；
  - **左侧 4 枚入口徽章（天赋 / 套装 / 兵符 / 神兵）**：更换为圆润厚涂徽章底框与顶部 Q 版胶囊数值标签（`天赋+1`、`+10%`、`0/2` 等），并在有可解锁/可升级条件时触发微幅呼吸与摇摆红点。

### 2.3 核心保留项（严禁改乱）
> [!IMPORTANT]
> - **右上角 6 格装备图标（`eq_1 ~ eq_6`：玉佩 / 扳指 / 战甲 / 战袍 / 战靴 / 护腕）**
> - **下方背包内的宝石图标（`gem_hex` 六边形品质宝石）**
> 以上两类图标**严格维持原有的简洁样式不变**，本轮只优化其外框品质底板（更加圆润温和的品质描边与流云内衬）和整个背包的暖木纹大底板。

### 2.4 全局底部 5 个导航 Tab 同步升级
- 将底部导航栏（`renderBottomNavBar`）全局统一应用到 **军需 / 主公 / 征战 / 武将 / 城防** 全部 5 个页签：
  - 换装更饱满、辨识度更高的 Q 版厚涂大图标（`48×48`~`52×52` 比例）：军需篮包（`tab_q_shop`）、主公羽翎盔（`tab_q_lord`）、双铁剑（`tab_q_battle`）、红缨武将盔（`tab_q_hero`）、城楼女墙（`tab_q_base`）；
  - 选中态采用暖金流光圆角高亮卡框 + 图标上浮放大，未选中态配深暖棕底衬与底部文字标签；
  - 全局挂载待办红点（军需可领、主公可点天赋/可合成、武将可升级）。
