# 《主公别放箭》武将技能设计与 GIF 特效命名规范

> **适用范围**：`art_src/raw/` 原始特效 GIF 投放、序列帧转换（`tools/art/gif_to_sheet.py`）、微信分包加载（`assets/bundles/art_battle/`）及英雄多技能接入规划。

---

## 一、GIF 存放路径与统一命名规范

### 1. 存放位置与命名模板

请将所有英雄技能释放的原始 GIF 图统一放入 **`art_src/raw/`** 根目录，并严格按照以下 5 段式下划线命名：

```text
skill_<英雄ID>_<英雄拼音>_<技能槽位>_<技能英文代号>.gif
```

#### 字段说明

| 字段 | 取值规则 | 说明 |
| :--- | :--- | :--- |
| 前缀 | 固定 `skill` | 区分普通静帧立绘（`hero_*.jpg`）、UI 图（`ui_*.jpg`）与场景背景图（`bg_stage*.jpg`） |
| `<英雄ID>` | `H01` ~ `H12` | 与 [configs.ts](file:///e:/sanguo/sanguo/assets/scripts/core/configs.ts) 中 `HERO_CONFIGS[].id` 一一对应，确保程序 100% 唯一匹配 |
| `<英雄拼音>` | `zhaoyun`、`zhugeliang` 等 | 方便美术与策划人员一眼识别归属武将，避免只看编号出错 |
| `<技能槽位>` | `s1` / `s2` / `ult` | `s1` = 普攻/基础核心技；`s2` = 进阶触发技（如第 N 次普攻/词条触发）；`ult` = 无双超武终极大招 |
| `<技能英文代号>` | 小写英文单词（如 `pierce`） | 描述技能表现形式，便于后期排查单个特效 |

#### 自动映射对应关系（为什么这样命名就能找到）

通过 `skill_<HeroId>_*_<slot>_*.gif` 前缀规则，脚本与程序无需手写繁琐的中文文件名映射表即可自动建立全链路对应关系：

1. **原始文件（`art_src/raw/`）**  
   `art_src/raw/skill_H05_zhugeliang_s1_lightning.gif`
2. **批量切帧打包（`tools/art/gif_to_sheet.py`）**  
   自动正则解析 `^skill_(H\d{2})_[a-z]+_(s1|s2|ult)_[a-z0-9_]+\.gif$` → 拆帧去黑底 → 生成横向雪碧图：  
   `assets/bundles/art_battle/vfx_H05_s1.png`（除第 1 关首包核心外，其余全入微信分包 `art_battle`，严控主包 `<= 800KB`）
3. **客户端代码映射（`ArtAssetManager.ts` & `BattleWorld.ts`）**  
   事件 `BattleVfxEvent` 通过 `type` 或 `heroId + skillSlot` 直接拼出 `vfx_${heroId}_${slot}` 读取 `getSheetFrames('vfx_H05_s1', 8)` 播放帧动画，缺图时自动回退现有矢量/基础贴图，永不报错崩溃。

## 二、GIF 美术制作技术规格（重要）

为了避免出现类似“白底/黑框遮挡战场”或微信小游戏包体超标，制作或筛选 GIF 时请遵守以下标准：

| 规格项 | 建议标准 | 原因说明 |
| :--- | :--- | :--- |
| **底色要求** | **纯黑底（`#000000`）发光特效** 或 **真透明底 RGBA GIF** | **严禁纯白底**！黑底可由 `gif_to_sheet.py` 按亮度无损转为透明通道并叠加 `ADD` 发光；白底边缘必现白边/白框 |
| **画布尺寸** | 单帧宽高建议 `256×256` ~ `400×400`（正方形或竖长构图） | 转雪碧图时统一缩放到 `128×128` 或 `128×144` 单帧，兼顾清晰度与图集尺寸 |
| **GIF 帧数** | 原片建议 `16 ~ 40` 帧（关键动作清晰），切帧取 `8` 帧（大招 `10~12` 帧） | 8 帧横向雪碧图约 `80~140 KB`，满足 36 套技能接入后战斗子包仍控制在 `<= 2.5MB` 附近（可按需对 `s1` 采用 `96×96` 单帧进一步压缩至 `45KB`） |
| **方向朝向** | 指向性技能（枪芒/刀气/箭雨）默认**朝正上方（12点方向）或正右方（3点方向）**；范围技（阵法/火海/砸地）**中心对齐画布正中** | 便于 `BattleView.ts` 按目标角度 `Math.atan2(dy, dx)` 直接旋转复用 |
