# 三国塔防 · 第3阶段与正式上线路线图（M1 首测闭环 · M2 长线与裂变）

> **定位**：衔接《威胁与战力平衡设计 v1》（第 1 阶段，已完成）与《第 2 阶段优化方案 v2》（固定坑位 · 军令与无双 · 12 武将羁绊与进化），补齐微信小游戏**首测买量留存、首单变现、正式提审收口、长尾玩法与社交裂变**全链路能力。
> **架构策略（已确认）**：渐进式演进——**M1** 扩展 `PlayerProfile`（schema v3 → v4）走客户端驱动 + 现有 `IDataRepository` / `IShopService` / `IAdService` 抽象（本地零依赖可测，上线无缝切微信支付与后端同步）；**M2** 好友榜走微信开放数据域，无尽全服周榜接入现有 NestJS + Redis `ZSET` + 战斗回放校验。
> **引擎与运行环境**：Cocos Creator 3.8.7（TypeScript）· 微信小游戏 · NestJS + Prisma + Redis。

## 1. M1 · 首测上线闭环（优先实施）

### 1.1 新手前 3 分钟分步引导（`TutorialOverlay`）

**目标**：解决新号进入第 1 关不理解坑位类型、军令拖拽与无双时机导致的前 30 秒高流失。

| 步骤 (`tutorialStep`) | 触发时机 | 引导动作与 UI 表现 | 设计要点 |
| :---: | :--- | :--- | :--- |
| **1** | 首次进入第 1 关点将后 | 遮罩挖洞高亮第 1 关推荐阵位，引导落位首发武将 | 强化「固定坑位」与坑位色环认知 |
| **2** | 第 1 波出怪满 3 秒 | 弱引导按住左侧「万箭齐发」按钮拖拽至敌群释放 | 体验 0.25× 瞄准慢动作与主动清场爽感 |
| **3** | 首次升 Lv.2 选卡弹窗 | 高亮卡片上的羁绊进度角标（如 `五虎 1/4 → 2/4`） | 建立「凑羁绊」构筑意识 |
| **4** | 首次怒气满 100 | 脉冲高亮右侧「无双」大圆按钮，引导点击清屏 | 形成第一局的核心记忆高潮点 |
| **5** | 首关胜利返回大厅 | 引导进入锻造/装备页穿戴首通掉落装备并强化 1 次 | 打通「推关 → 局外变强 → 推下一关」闭环 |

- **实现约束**：提供右上角“跳过引导”按钮；仅在 `tutorialStep < 99` 且非自动化测试环境触发；进度持久化至 `PlayerProfile.tutorialStep`。

### 1.2 每日任务 / 活跃度宝箱 + 七日新手目标

#### 每日任务（0 点跨天重置，复用 `PlayerDataManager` 跨天刷新机制）
- **任务池（5 分钟每日必做清单）**：
  1. 每日登录游戏（+15 活跃）
  2. 参与任意战役 1 次 / 3 次（+15 / +20 活跃）
  3. 累计击杀敌军 200 名（+15 活跃）
  4. 强化任意装备部位 1 次（+15 活跃）
  5. 宝石合成 1 次或洗炼 1 次（+15 活跃）
  6. 领取巡逻挂机收益 1 次（+10 活跃）
  7. 观看激励视频 1 次（+15 活跃）
- **活跃度阶梯宝箱**：
  - **30 活跃**：铜钱 ×1200 + 粮草 ×10
  - **60 活跃**：锻造石 ×8 + 随机 1~2 品宝石 ×2
  - **100 活跃**：元宝 ×80 + 随机名将将魂 ×5

#### 七日新手目标（创角前 7 天逐日解锁，开放 14 天可补领）
- **每日目标示例**：Day1 通关第 3 关 / 穿戴 2 件装备；Day2 合成 2 品宝石 / 升级 1 名武将；Day3 单局激活 2 组羁绊 / 升级城防科技；Day5 通关第 10 关；Day7 累计登录 7 天。
- **终极里程碑奖励**：完成 18/24 项任务赠送 **核心高人气武将（吕布/诸葛亮将魂箱）+ 5 品专属攻击宝石**，作为 7 日留存强锚点。

### 1.3 6 元首充礼包 + 赛季军功战令

#### 6 元首充礼包（分 3 天领取，拉升次留与 3 留）

- **支付对接**：全部走现有 `IShopService.purchase(productId)`，本地单测与沙箱环境可直接触发发奖，微信小游戏提审版本切换真实 `wx.requestMidasPayment` / 服务端回调。

## 2. M2 · 长线玩法与生态裂变（首测跑通后迭代）

### 2.1 无尽爬塔模式（「过关斩将 / 赤壁无尽」）

- **解锁与次数**：通关第 10 关开放；每日免费 2 次 + 激励视频额外 1 次。
- **低成本高复用设计**：
  - 直接沿用第 1 阶段 `RunConfig.getWaveHpScale(w) = hpMulBase^(w - 1)`，从 W21 起无限外推；
  - 每 5 波固定 1 名机制 Boss（轮换 10 大 Boss），每 10 波轮换全局环境词缀（如「连环铁索」火伤+30%/移速+15%、「八阵迷雾」远程射程-15%/暴击+20%）；
  - 复用 `BattleWorld` 确定性 `opLog` 回放能力，高波次成绩上报后端校验防改数据。
- **奖励与全服周榜**：
  - 首次突破波次里程碑（W25 / W30 / W40 / W50…）发放一次性元宝与高品宝石；
  - 后端 NestJS + Redis `ZSET` 维护全服周榜，每周一 0 点结算称号与养成材料奖励。

### 2.2 局内三国典故奇遇 / 风险收益事件

在主线（第 5 关起）或无尽模式的第 6~16 波之间随机触发 1~2 次（复用 `CRISIS_CHOICE` 暂停弹窗 UI，每事件提供 2~3 个风险收益选项）：

| 典故事件 | 选项 A（高风险高收益） | 选项 B（稳健收益） |
| :--- | :--- | :--- |
| **草船借箭** | 立即额外引出 1 波高速木鸢/轻骑，15 秒内未漏怪则**军令冷却永久 -15% + 1 次高品质三选一** | 直接获得 +25 怒气与少量经验 |
| **空城计** | 全体武将主动停火 3 秒，换取**城墙回复 25% + 怒气瞬间 +50** | 稳守阵线，全军攻速 +15% 持续 15 秒 |
| **火烧连营** | 接下来 2 波敌军移速 +25%，但全军**火攻与暴击伤害 +45%** | 本波直接释放 1 次免费火攻军令 |

### 2.3 微信小游戏社交裂变与回流

1. **微信好友排行榜（开放数据域）**：通过 `wx.setUserCloudStorage` 上报 `maxClearedStage` 与 `endlessBestWave`，大厅新增「好友榜」按钮（纯开放数据域零后端成本）。
2. **战报炫耀分享 & 邀请裂变**：
   - 3 星首通、无尽破纪录、达成 100 连斩时弹出“炫耀战绩”按钮，生成含 **MVP 武将 + 伤害占比 + 激活羁绊** 的分享卡片；
   - 每日首次分享领 15 粮草；邀请新好友进入游戏累计领取将魂箱与元宝。
3. **微信订阅消息提醒**：粮草自然回满、巡逻收益满 12 小时时触发一次性订阅消息推送，提升日内回流与次日留存。

## 3. 存档 Schema v3 → v4 扩展与模块复用

在现有 `PlayerProfile`（schema v3）基础上增量扩展以下字段，`PlayerDataManager` 加载旧存档时自动补齐默认值（保持 v2 → v3 → v4 迁移测试全绿）：

```ts
export interface PlayerProfileV4Extension {
  schemaVersion: 4;
  tutorialStep: number; // 0=未开始, 1~5=进行中, 99=已完成
  dailyQuests: {
    date: string;
    progress: Record<string, number>;
    claimedIds: string[];
    claimedActiveBoxes: number[]; // [30, 60, 100]
  };
  sevenDay: {
    startDate: string;
    progress: Record<string, number>;
    claimedIds: string[];
    milestoneClaimed: boolean;
  };
  firstRecharge: {
    purchased: boolean;
    purchaseDate?: string;
    claimedDays: number[]; // [1, 2, 3]
  };
  battlePass: {
    seasonId: number;
    exp: number;
    premiumUnlocked: boolean;
    claimedFreeLevels: number[];
    claimedPremiumLevels: number[];
  };
  endless: {
    bestWave: number;
    dailyLeft: number;
    adExtraLeft: number;
    lastDate: string;
    claimedMilestones: number[];
  };
  shareStats: {
    lastShareDate: string;
    dailyShareClaimed: boolean;
    invitedCount: number;
    claimedInviteMilestones: number[];
  };
}
```

### 与第 1 / 第 2 阶段核心模块的复用关系
- 奇遇事件 Buff 直接通过第 2 阶段 `StatBlock.add({ source: 'event:xxx', expireAt })` 注入；
- 每日/七日任务进度通过统一事件钩子（战后结算、装备强化、宝石合成、巡逻领取、广告回调）自动累加；
- 无尽模式直接复用 `WaveDirector` + `getWaveHpScale(w)` + 靶场/回放校验框架。
